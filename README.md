# 最强蜗牛插件

`astrbot_plugin_marvelous_snail` 目前功能是一个用于监控微信公众号 **最强蜗牛** 文章更新并自动推送到指定会话的 AstrBot 插件。通过配置第三方公众号文章导出 API，插件可以定期检测指定公众号作者是否发布了新文章，并及时通过私聊或群聊通知用户。

## ✨ 功能特性

- 🔍 搜索公众号作者（仅支持“最强蜗牛”关键词）
- ⭐ 将搜索结果中的公众号作者添加至监控列表
- 📋 查看已保存的监控作者列表
- ⏱ 基于 Cron 表达式的定时轮询检测
- 📨 新文章自动推送到已开启通知的会话（支持私聊/群聊）
- 🛡 安全的 API 认证与错误处理

## 📦 安装

### 前置条件

- 运行在 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 框架之上。
- 已部署并正确配置 **微信公众号文章导出 API**（需自行搭建或使用第三方服务）。

### 安装插件

1. 将插件文件夹放入 AstrBot 的 `plugins` 目录下，或通过 AstrBot 插件市场安装（如已上架）。
2. 重启 AstrBot 或使用插件管理命令加载插件。

## ⚙️ 配置说明

在 AstrBot 的配置文件中为该插件添加如下配置段：

```json
{
  "exporter_api_url": "https://your-api-domain.com",
  "exporter_auth_key": "your-secret-key",
  "updata_cron": "*/30 * * * *"
}
```

| 配置项              | 必填 | 说明                                                         |
| ------------------- | ---- | ------------------------------------------------------------ |
| `exporter_api_url`  | ✅   | 微信公众号文章导出 API 的根地址（不包含尾随斜杠）            |
| `exporter_auth_key` | ✅   | 与 API 通信所需的认证密钥                                    |
| `updata_cron`       | ❌   | Cron 表达式，控制自动检测更新的频率。若不填则禁用自动检测。示例：`*/30 * * * *` 表示每30分钟执行一次 |

## 📖 使用命令

| 命令格式                 | 功能说明                                                     |
| ------------------------ | ------------------------------------------------------------ |
| `zqwn [关键词] [数量]`   | 搜索公众号作者。默认关键词为“最强蜗牛”，返回前5个结果。**注意**：目前仅支持关键词“最强蜗牛”。 |
| `zqwn_add <索引>`        | 将 `zqwn` 命令返回的搜索结果中指定索引的作者添加到监控列表。 |
| `zqwn_list`              | 列出当前已保存监控的公众号作者。                             |
| `推送zqwn 开启`          | 在当前会话（私聊或群聊）开启新文章自动推送。                 |
| `推送zqwn 关闭`          | 在当前会话关闭自动推送。                                     |
| `获取推送列表`           | 查看所有已开启自动推送的会话标识（如用户ID/群ID）。          |

### 使用流程示例

1. **搜索作者**  
   ```
   zqwn 最强蜗牛 5
   ```
   机器人返回类似：
   ```
   搜索结果:
   1: 最强蜗牛
   2: 蜗牛情报站
   ...
   ```

2. **添加监控**  
   ```
   zqwn_add 1
   ```
   机器人确认：`✅ 已添加作者: 最强蜗牛`

3. **开启本会话推送**  
   ```
   推送zqwn 开启
   ```
   机器人回复：`✅ 你的会话ID 已开启自动推送`

4. 当监控的作者发布新文章时，机器人会自动向已开启推送的会话发送文章链接。

## 🧪 依赖项

- `aiohttp`：异步 HTTP 客户端

> 以上依赖通常已包含在 AstrBot 环境中。

## 🚧 注意事项

- 本插件依赖外部公众号文章导出 API，请确保 API 可用且接口规范与代码中的路径一致：
  - `GET /api/public/v1/account`：搜索公众号
  - `GET /api/public/v1/article`：获取文章列表
- 自动检测时的请求间隔会随机浮动 ±5 秒（最小不低于5秒），避免请求过于规律。
- 推送功能基于 AstrBot 的统一会话消息接口，支持私聊和群聊。

## 📝 开发说明

- 插件使用 AstrBot 的 KV 存储（`get_kv_data` / `put_kv_data`）持久化监控作者列表、文章记录和推送用户列表。
- 定时任务通过 `apscheduler` 的 `AsyncIOScheduler` 管理，支持动态更新 Cron 表达式。
