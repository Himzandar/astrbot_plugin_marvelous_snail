# 🐌 最强蜗牛插件

`astrbot_plugin_marvelous_snail` 是一个面向 AstrBot 的微信公众号文章监控插件，当前聚焦于最强蜗牛相关公众号内容。插件通过对接第三方 wechat-article-exporter 风格接口，完成作者搜索、监控作者管理、定时拉取最新文章、自动推送、本地文章缓存与查询、以及密令解析功能。

---

## 📁 项目结构

```
astrbot_plugin_marvelous_snail/
├── main.py            # 🎯 插件主逻辑、命令处理和定时任务
├── parse.py           # 🔍 消息解析、格式化与中文相关度搜索
├── utils.py           # 🔧 Cron文本化工具和消息发送辅助
├── code.py            # 🔐 密令解析核心逻辑
├── metadata.yaml      # 📋 插件元信息
├── _conf_schema.json  # ⚙️ 配置项定义
└── README.md          # 📖 使用说明
```

### parse.py - 消息解析与搜索 🔍

`parse.py` 包含 `Parse` 类，提供文章数据的解析、分页和中文相关度搜索功能。

**📋 Parse类方法：**

| 方法名 | 功能说明 |
|--------|----------|
| `get_author_all_title_and_link` | 📖 读取本地JSON文件，获取指定作者的所有文章标题+简介和链接 |
| `chinese_relevance_score` | 🎯 使用Jaccard相似度算法计算两个中文字符串的相关度分数 |
| `search_chinese_relevance` | 🔍 根据中文相关度对文章数据进行搜索和排序 |
| `parse_title_send_link` | 📝 解析文章标题并返回相关链接列表 |
| `Paging_strategies` | 📄 将攻略列表分页，支持上一页/下一页导航 |

**📊 中文相关度搜索说明：**
`chinese_relevance_score` 方法使用结巴分词对标题和查询词进行分词，然后计算Jaccard相似度：
```
相似度 = 交集词数 / 并集词数
```
结果范围为0到1，值越大表示相关性越高。

**📑 分页机制：**
`Paging_strategies` 方法将攻略列表每5条分为一页，支持：
- 当前页码和总页码显示
- 上一页/下一页导航
- 返回分页后的消息列表和数据映射

### utils.py - 工具函数 🔧

`utils.py` 提供两个工具函数：

#### cron_to_human ⏰

将5段Cron表达式转换为中文易读描述。

**📋 参数：**
| 参数名 | 类型 | 说明 |
|--------|------|------|
| `cron` | `str` | 5段Cron表达式（分 时 日 月 周） |

**📋 返回：**
| 类型 | 说明 |
|------|------|
| `str` | 中文易读描述字符串 |

**💡 示例：**
```python
cron_to_human("0 5 * * *")      # 返回 "每天 5点"
cron_to_human("*/30 * * * *")    # 返回 "每30分"
cron_to_human("0 8 * * 1-5")    # 返回 "周一至周五 8点"
```

#### send_msg 💬

发送消息并返回消息ID，支持Aiocqhttp平台特殊处理。

**📋 参数：**
| 参数名 | 类型 | 说明 |
|--------|------|------|
| `event` | `AstrMessageEvent` | 消息事件对象 |
| `msg` | `str` | 要发送的消息内容 |

**📋 返回：**
| 类型 | 说明 |
|------|------|
| `int \| None` | Aiocqhttp平台成功返回消息ID，其他平台返回None |

**📋 parse_code函数：**

## ✨ 功能特性

### 🚀 已实现功能

1. **🔍 公众号作者搜索** - 搜索公众号作者（当前仅支持"最强蜗牛"关键词）
2. **➕ 作者监控管理** - 添加/删除监控作者，查看已保存的监控作者列表
3. **⏰ 定时检查更新** - 按Cron表达式定时检查作者是否发布新文章
4. **🔔 自动推送消息** - 自动推送新文章到已开启推送的私聊或群聊
5. **📚 文章搜索查询** - 搜索本地缓存的文章（基于中文相关度）
6. **📄 文章分页浏览** - 文章分页显示和翻页功能
7. **💾 本地数据存储** - 本地JSON文件持久化存储文章和密令
8. **🔐 密令自动解析** - 自动解析最强蜗牛文章中的密令
9. **🔑 密令快捷查询** - 监听消息中的"密令"关键词，自动发送有效密令列表
10. **⏱️ 智能请求间隔** - 请求间隔随机延迟，防止过度请求被封
11. **🗑️ 过期密令清理** - 自动删除2个月前的过期密令

---

### 🔄 定时更新工作流程

1. **⏰ Cron触发** - 定时任务触发`get_saved_account`方法
2. **📋 遍历作者** - 遍历KV存储中的监控作者列表
3. **📥 获取文章** - 调用文章接口获取每位作者的最新文章
4. **🔍 比对更新** - 与KV中记录的aid比对：
   - ❌ 无更新：记录日志并保留旧数据
   - ✅ 有新文章：更新本地JSON文件，并通过`_send_message`推送
5. **🔐 密令解析** - 如果是最强蜗牛的文章，自动解析并推送密令
6. **⏱️ 随机延迟** - 请求间隔加入随机延迟（5-10秒）

---

### 📚 文章搜索交互流程

1. **🎯 用户发起搜索** - 用户发送`搜索攻略 <关键词>`命令
2. **📁 读取数据** - 读取`plugin_data`目录下所有作者JSON文件
3. **👤 选择作者** - 显示已保存的作者列表，用户回复编号选择
4. **🔍 相关度搜索** - 使用中文相关度算法搜索该作者的所有文章
5. **📄 分页显示** - 返回分页后的结果列表，支持翻页
6. **📤 发送链接** - 用户选择文章编号，发送文章链接


### 📊 配置项详细说明

| 配置项 | 必填 | 类型 | 默认值 | 说明 |

## 💾 数据存储

### 📊 KV存储键

| 键名 | 说明 |
|------|------|
| `authors` | 监控中的作者名到fakeid的映射 |
| `articles` | 每个作者最近一次已记录文章的信息 |
| `users` | 接收自动推送的会话信息 |

---

### 📁 本地文件存储

插件会在 AstrBot 数据目录下写入：

```
data/plugin_data/astrbot_plugin_marvelous_snail/
├── 最强蜗牛.json          # 作者文章归档文件
├── 其他作者.json
└── codes/
    ├── codes.json          # 有效密令存储
    └── code_error.json     # 解析失败的链接记录
```

---

### 📄 作者JSON文件结构

每个作者对应一个JSON文件，例如 `最强蜗牛.json`：

```json
{
  "num": 3,
  "articles": [
    {
      "aid": "xxx",
      "title": "文章标题",
      "digest": "文章摘要",
      "link": "文章链接",
      "author_name": "作者名称"
    }
  ]
}
```

---

### 🔐 密令JSON文件结构

密令存储在 `codes/codes.json`：

```json
{
  "num": 10,
  "code": {
    "密令1": "2024-06",
    "密令2": "2024-06"
  }
}
```

**📋 说明：**
- 密令值为月份字符串，用于过期判断
- 超过2个月的密令会自动删除

## 📌 注意事项

- ⚠️ 搜索命令目前只接受"最强蜗牛"这一固定关键词
- ⚠️ 自动检查任务是否注册，取决于 `updata_cron` 是否配置有效
- ⚠️ 如果没有配置推送用户，即使检测到新文章，也不会发送消息
- ⚠️ 推送消息包含文章信息和链接
- ⚠️ 自动轮询作者时，请求间隔会在基础延时上增加随机抖动
- ⚠️ 私聊场景下，推送列表里展示的标识是发送者名称
- ⚠️ 文章搜索使用中文相关度算法，基于结巴分词和Jaccard相似度
- ⚠️ 攻略分页每页显示5条，支持翻页导航
- ⚠️ 选择超时时间为20秒
- ⚠️ 密令自动解析功能仅对"最强蜗牛"作者生效
- ⚠️ 密令默认保留2个月，过期自动删除
